# MASIX TECHNOLOGIES 🚀  
**Filtering What Matters**

MASIX Technologies is a modern digital solutions platform focused on **AI, Technology, and Innovation**. This project represents a responsive multi-page website built with clean design, reusable styling, and scalable structure.

---

## 🌐 Live Overview
This project is a **frontend website** showcasing:
- Company branding
- Services
- About information
- Contact interface

---

## 📁 Project Structure

```
MASIX/
│── index.html        # Home page
│── about.html        # About page
│── services.html     # Services page
│── contact.html      # Contact page
│── style.css         # Global styles (all styling centralized)
│── script.js         # JavaScript functionality
│── logo.png          # Company logo
│── bg.jpg            # Background image
```

---

## ✨ Features

- 🌌 **Modern UI Design** with glassmorphism effects
- 📱 **Responsive Layout** (works across devices)
- 🎨 **Centralized Styling** using a single CSS file
- ⚡ **Lightweight & Fast**
- 🔍 Basic **Search Interaction (UI simulation)**
- 📩 Contact form UI
- 🔗 Multi-page navigation

---

## 🛠️ Technologies Used

- **HTML5** – Structure

## 🚀 How to Run Locally

1. Download or clone the repository:
   ```bash
   git clone https://github.com/your-username/masix.git
   ```

2. Open the project folder

3. Double-click:
   ```
   index.html
   ```
   OR right-click → **Open with browser**
